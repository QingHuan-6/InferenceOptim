# AutoDL 候机室本地使用

工具独立安装在 `.local-tools/autodl-monitor`，不属于毕设推理实现。
上游仓库：https://github.com/cc2025cheng/Stop-Manually-Refreshing-AutoDL-GPU

本次安装版本为 v0.2.1，提交为 `7f5bee990e89d0b5f5c55df792ef26f4b39d1f9c`。
Node.js 22 便携运行时位于 `.local-tools/node-runtime`，已对照官网下载的 SHA256 校验，
依赖通过锁文件和 `npm ci --ignore-scripts` 安装。未修改全局 Node.js 配置。
工具、依赖、日志、专用浏览器登录资料均被项目 `.gitignore` 排除。

## 启动和停止

在项目根目录执行：

```powershell
./scripts/start-autodl.ps1
```

打开 http://127.0.0.1:8787 。后台在隐藏窗口运行，关闭网页不会停止后台。
停止后台：

```powershell
./scripts/stop-autodl.ps1
```

停止本地后台不会关停云端实例，也不会停止云端计费。
监测期间电脑必须联网且不休眠。不要向局域网或公网共享本地控制台。
不要分享 `.local-tools/autodl-monitor/.runtime`，其中包含专用浏览器资料与任务状态。

## 本次抢卡条件

- GPU：RTX 4090，1 张；同步真实目录时确认具体型号及显存。
- GPU 小时租金：不超过 2 元/小时。
- 地区：不限，可多选。
- 镜像：登录后根据真实可选列表选择 PyTorch/CUDA 环境，记录具体版本。
- 费用：GPU 小时上限不等于总费用上限；另外核对数据盘与其他收费项。
- 初始模式：只通知，停在提交之前；安装本身不创建或租用实例。

## 首次登录与配置

1. 点击“连接 AutoDL → 打开登录”，在专用浏览器中本人完成登录和验证。
2. 返回控制台，点击“检查登录状态”，确认“会话可用”。
3. 多选可接受地区，同步 AutoDL 型号；选择单张 4090。
4. 选择新建实例，同步官方镜像；先核对 GPU 单价、磁盘和最终报价。
5. 初次以“只通知”模式检查流程。自动创建需要在界面另行明确费用授权。

当前毕设 README 仅描述 mock 框架，尚未包含真实模型依赖和显存需求，
不适合作为 AI 选卡的完整依据。本次型号已明确，不需要配置 AI Key。

自动创建后要在 AutoDL 控制台确认实例和计费状态，并开始使用或及时关机。
本地工具不是自动关机或消费封顶工具；不要在不准备使用 GPU 时开启自动租用。
